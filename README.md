# Django Starter

Minimal Django starter project generated with `django-admin startproject`.

## Setup

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -e .
```

## Run Checks

```sh
.venv/bin/python manage.py check
```

## Start The Development Server

```sh
.venv/bin/python manage.py runserver
```
